## Pre Requests Softwares. ##
    **1. SSH TOOLS (Secure Shell Tools) : It is a Cryptographic Network protocal used to securely connect to remote systems over an unsecured network. 
         The SSH Tool refers to software that  allows users to establish as SSH Connection to a remote Server or Device.
         Common SSH Tools are
         1.Putty
         2.Super Putty
         3.MobaXterm

  **2. FTP TOOLS ( FILE TRANSFER PROTOCOL ) : It is a Network protocol used to transfer files between a client and a server over the internet or a local network. 
       An FTP Tool is a Software Application that allows users to manage file transfers using FTP.

       ** How FTP Works ?
          ==> Client-Server Model: An FTP Client connects to an FTP Server to Upload/Download files.
          ==> Authentication : Requires a Username nd Password (or can allow anonymous access)
          ==> Active & Passive Mode : Determines how the data connection is established.
