
# ** System Resource Commands ** #

|                       Command                           |                        Description                          |
|---------------------------------------------------------|-------------------------------------------------------------|
|                        `who`                            |    Displays the current users working on the system.        |
|                         `w`                             |    Shows who is logged on and what they are doing.          |
|                       `users`                           |  Displays a compact list of users currently logged in.      |
|                       `whoami`                          |  Displays the current user executing the command.           |
|                       `whereis`                         |  Locates the binary, source, and manual pages for a command.|
|                       `date`                            |  Prints or sets the system date and time.                   |
|                        `df`                             |  Reports file system disk space usage.                      |
|                        `du`                             |  Estimates file or directory disk space usage.              |
|                      `hostname`                         |  Displays or sets the system's hostname.                    |
|          `ifconfig` / `hostname -i` / `ip a`            |  Finds the system's IP address.                             |
|                     `man <command>`                     |  Displays the manual page for a command.                    |
|                     `info <command>`                    |  Provides detailed documentation on a command.              |
|                      `help <command>`                   |  Displays a brief help summary for a command.               |
|                      `whatis <command>`                 |  Displays a one-line summary from the manual for a command. |
|                   `service <service-name> status`       |  Checks the status of a system service.                     |
|                   `systemctl list-unit-files`           |  Lists all available services.                              |
|                      `uptime`                           | Shows how long the system has been running.                 |
|                        `last`                           | Displays the list of last logged-in users.                  |

###   How to Save & Exit Vim After Writing These Commands  ###
1. Open the file in Vim:
   sh
   vim system_commands.txt
   
2. Press `i` to enter **Insert Mode**.
3. Copy-paste the above formatted table  into your file.
4. Press `Esc` to exit Insert Mode.
5. Type `:wq` and press Enter to save & exit.
