# User / Group Administration Commands #

1. useradd = creates a new account ( *Only  root User can execute this command* )
2. passwd = changes a user's password.
  # Note : *Old password is first requested then new password is requested twice for confrimation*.
3. chage = it is used to see user related "thresold details* such as user disable time etc.
4. groupadd = Create a new group. ( *Only root user can execute this command* ).
5. usermod = changes user attributes. ( *Only root user can execute this command* ).
6. id = it is one more command which will show the user details such as his primary group and his secondary group.
7. groups = Displays group membership means displays the which user belongs to which group.
8. lid = Displays user's group or group's user.( *Only root user can execute this command* ).
9. su =  To Switch user to come out from the user press ctrl + d logout or exit .
10. sudo = Execute a command as another user.
11. userdel = Removes a user Account . ( *Only root user can execute this command* ). 
12. groupdel = Delete group . ( *Only root user can execute this command* ).
