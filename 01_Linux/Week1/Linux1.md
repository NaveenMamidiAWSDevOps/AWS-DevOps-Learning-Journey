## **Introduction**  

### **Q. What is Linux?**  
Linux is an open-source, Unix-like operating system that powers most servers, cloud infrastructures (AWS, Azure), and DevOps tools.  

🔹 Used for server management, scripting automation, and deploying applications.  
🔹 Provides a Command-Line Interface (CLI), essential for automation in DevOps.  

---

### **Linux File System Hierarchy**  
Linux follows a structured file system hierarchy. Below are some important directories:  

📌 **Important Directories:**  

| Directory | Purpose                                  |
|-----------|------------------------------------------|
|   /       | Root directory (everything starts here). |
|   /home   | User home directories.                   |
|   /etc    | System configuration files.              |
|   /var    | Log files and variable data.             |
|   /usr    | Installed software and shared libraries. |
|   /bin    | Essential system commands.               |
|   /tmp    | Temporary files.                         |
